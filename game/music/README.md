# Céu Lavanda — projeto FamiStudio

Tema original de chiptune sombrio para **Sete Balões**, criado com a sensação inquietante de trilhas 8-bit de cidades fantasma, sem reutilizar a melodia de *Lavender Town*.

## Abrir e editar

1. Use o FamiStudio desktop 4.5.x.
2. Abra `ceu-lavanda-famistudio.txt` diretamente no FamiStudio.
3. Use **Save As** para salvar uma cópia em `.fms`.

O projeto usa apenas os quatro canais básicos do NES:

- `Square 1`: sino agudo e instável;
- `Square 2`: contrapulso dissonante;
- `Triangle`: baixo repetitivo;
- `Noise`: passos secos.

`ceu-lavanda-preview.wav` é uma prévia de duas voltas. `ceu-lavanda.nsf` pode ser executado em emuladores e players compatíveis com Nintendo Sound Format.
